# 冒险、3D 城镇与战斗操作

快捷键在对应画布或界面获得焦点时生效；输入框、文本域和下拉框不会截获大多数游戏快捷键。macOS 可用 **⌘** 代替 **Ctrl**。

## 全局冒险界面

| 操作 | 功能 |
| --- | --- |
| 左键己方英雄 | 选择英雄 |
| 左键可达格/对象 | 沿校验后的路径移动并交互 |
| 左键英雄脚下的对象 / **Space** | 再次交互当前格 |
| **H** / **Shift + H** | 下一位 / 上一位存活己方英雄 |
| **T** | 进入英雄所在的友方城镇 |
| **N** | 结束回合 |
| **M** | 展开/收起战略地图与 13 城图鉴 |
| **Ctrl/⌘ + S** | 保存到 `autosave` 槽 |
| **Ctrl/⌘ + O** | 打开战役保存/读取/新游戏菜单 |
| **?** / **F1** | 打开游戏内指南 |
| **Esc** | 离开城镇、收起战略图或关闭当前对话框（依焦点而定） |

英雄面板显示有效主属性、经验、移动力、法力、7 个军队格与装备入口。顶部显示 10 种资源和日历，右侧小地图可选择英雄或移动。

## 可交互 3D 城镇

进入友城后，左侧/中央是实时 3D 场景，右侧是功能面板。顶部五个页签为概览、建设、招募、军队管理和魔法书；所有功能都可以不点击模型而完成。

### 建筑点击后的去向

- 点击**未建模型**：定位其建设卡，仍需确认费用与前置，不能直接建造。
- 点击**已建兵种巢穴**：打开对应兵种招募卡。
- 点击**堡垒**：打开英雄与守军调动。
- 点击**法师公会**：查看来访英雄魔法书；没有该建筑时会提示先建造。
- 点击**其他已建建筑**：在概览中定位其经济与功能说明。

“Town buildings”列表提供与 9 个模型等价的按钮，适合键盘和触屏。建造后模型原地更新，不会重建整个场景。

| 输入 | 功能 |

| 左拖 | 平移 |
| 右拖 / 中拖 | 旋转并调整俯仰 |
| 滚轮 / Ctrl + 滚轮 | 缩放 |
| Shift + 滚轮 | 平移 |

工具栏另有放大、缩小、左右旋转和重置按钮。离开城镇可使用页头按钮；未在画布中消费 **Esc** 时，也可用它返回冒险。

### 建造动画与播放控制

只有在建设卡中确认并成功支付建造后，新建筑才会播放一次八阶段组装动画；取消确认、建造失败、免费/脚本建设、AI 状态更新、读取存档和旧存档中的既有建筑不会触发动画。动画只改变模型展示，不会重复扣费、改变建造规则或影响招募与存档。

- **← / →**：切换到上一个 / 下一个阶段并暂停，便于逐阶段查看。
- **Pause / Play / Replay**：暂停、继续或重新播放。
- **Progress** 滑块：拖动定位；键盘可用方向键微调，**Home / End** 跳到起点 / 终点。
- **0.5× / 1× / 2× / 4×**：切换播放速度。
- 系统启用“减少动态效果”时直接显示最终模型，不自动播放；仍可静态查看各阶段。

动画播放时仍可切换城镇页签、招募或点击其他建筑，原有费用、前置和确认流程不变。离开城镇、读取战役或销毁场景会清理动画并恢复完整模型，不会撤销已经成功建造的建筑。

## 六角格战术战场

蓝环是攻方，红环是守方，金环标记当前行动队。绿色格可移动；敌人高亮表示可攻击，紫色高亮表示当前法术的有效目标。行动条、英雄法力、当前队属性与战斗日志均可直接查看。

| 输入 | 功能 |
| --- | --- |
| 左键绿色格 | 移动并结束当前队行动 |
| 左键敌军 | 射击，或移动到相邻格后近战 |
| 悬停敌军 | 预览伤害、移动费用、反击与射击惩罚 |
| **S** / Spell | 开关魔法书；需要单体的法术再点高亮目标 |
| **W** / Wait | 等待，轮末按反向顺序行动 |
| **D** / Defend | 防御并结束行动 |
| **A** / Auto | 开关自动战斗；开启后双方均由战术 AI 控制 |
| **H** / Help | 战场帮助 |
| **R** / **⌂** | 重置相机 |
| **Esc** | 取消所选法术、关闭魔法书或帮助 |

施法不消耗当前兵种队行动，但每英雄每轮限一次。群体、施法者及敌方英雄法术立即结算；单体法术需要有效目标。

### 战场相机

- 右拖旋转；中拖或 **Shift + 左拖**平移；滚轮缩放。
- 顶栏提供左右旋转、重置与缩放按钮。
- 触屏拖动旋转视角，轻点格子或兵种执行操作。

战斗结果出现后，查看幸存者与奖励，再选择“Return to adventure”写回并返回战役。自定义内容沙盒使用同一套操作，但结果显示后返回编辑器，不改变战役。

## 自定义内容工作区

开始界面或冒险界面的 **Content editor** 按钮可打开工作区；有待结算战斗时不能打开。打开期间战役命令暂停，关闭后恢复。非沙盒状态下 **Esc** 可关闭编辑器；沙盒中用 **Leave sandbox** 返回。字段、JSON 与验证流程见[自定义内容指南](./content-editor.md)。
